## 引言：自治透明化，從「查詢」開始

在任何自治組織的運作中，法規的透明與可及性是民主程序的基石。為了實現高師大附中學生會（簡稱本會）自治法規的公開透明與易於維護，我們開發了「高師大附中學生會自治法規共用系統」。
這是一個專為本校會員設計的 GitHub Pages 靜態網站，它將繁瑣的法規條文轉化為清晰、現代、易於查找的線上平台，大大簡化了資訊傳遞與網站維護的流程。

## 技術亮點：極簡架構下的現代美學

本專案雖為靜態網站，卻採用了當前前端開發的主流技術，確保了出色的使用者體驗和未來易於維護的架構：

 * 前端技術： 採用 純 HTML、CSS (Tailwind CSS) 和 JavaScript (ES6) 建置，實現了極致的載入速度和低維護成本。
 * 現代化 UI/UX： 透過整合 Daisy UI，網站介面呈現出乾淨、現代且高度響應式的設計風格。
 * 精緻的字型排版： 針對法律文本的清晰度做了優化，選用 未來熒黑 (Glow Sans TC) 等字型，確保了中文字體的美觀與可讀性，並針對條號等細節進行了特殊字型配置。
 * PWA 支援： 網站具備漸進式網頁應用程式 (PWA) 的能力，讓使用者可以像安裝 App 一樣將網站加入桌面，隨時存取重要法規。
 * 動態載入組件： 使用 JavaScript 的 fetch API 動態載入共用的頁首、頁尾與功能列表片段，使得法規頁面內容的統一更新變得異常簡單。


## 核心價值：專注於「查詢」與「精確」

本系統的設計核心宗旨是為本會會員提供一個清晰、無障礙的法規查詢平台：

 * 結構化呈現： 所有自治法規（如組織章程、選舉罷免法等）都經過結構化處理，並清晰區分「現行法規」、「校務章則節選」及「已廢止法規」，避免混淆。
 * 條文錨點（Highlight Feature）： 程式碼中設計了自動化腳本，能夠為法規條文（如第X條）自動生成可直接跳轉的錨點（#article-X），方便使用者在分享特定條文時能精準定位。
 * 聲明與溯源： 網站非常嚴謹地註明了法規的沿革查詢頁面和校官網的權威版本，確保使用者了解本網站僅為彙編工具，保障了資訊的準確性與法律效力層級。

## 🚀 下一步：持續優化與社群參與

我們致力於將此系統打造成最完善的學生自治資訊中心。目前的待辦清單（TODO List）也顯示了未來的發展方向，包括增加修法沿革時間軸和學生會自治法規制度程序的說明。
歡迎所有關心校園自治的師生點擊 Live Demo 連結 體驗，並隨時透過 GitHub 專案頁面（[您的 GitHub Repo 連結]）回饋建議或參與貢獻！
